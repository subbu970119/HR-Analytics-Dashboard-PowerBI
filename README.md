# HR Analytics Dashboard (Power BI)

A 5-page Power BI report analysing workforce, hiring, performance, satisfaction and attrition.

## Pages
1. **HR Overview** – headcount, active/inactive employees, average salary, age, satisfaction, attrition rate; breakdown by department, gender, location.
2. **Recruitment Dashboard** – candidates, time to hire, hiring cost, hiring status and source.
3. **Employee Performance Dashboard** – performance and manager ratings, training hours, promotions.
4. **Employee Satisfaction Dashboard** – job satisfaction, work-life balance, manager support, salary satisfaction by department.
5. **Employee Attrition Dashboard** – employees left, reasons for leaving, years worked before leaving.

## Data Model
Tables: `Employees`, `Recruitment`, `Performance`, `Satisfaction`, `Attrition`.

## Tools
Power BI Desktop, DAX measures, Power Query, data modelling.

## Key Insights
